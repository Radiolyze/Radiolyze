# docs-internal/

Working drafts from internal planning/analysis passes — not part of the
published documentation site (not referenced in `mkdocs.yml`'s nav).

They're kept here for historical context rather than deleted, since they
record the reasoning behind past prioritization decisions. Contents may
reference branches that no longer exist and status/dates that are stale
as of whenever they were last touched — treat them as point-in-time notes,
not living documentation.

If a plan's proposal is still relevant, track it as a GitHub issue instead
of updating the draft in place.

| File | Purpose |
| --- | --- |
| `documentation-improvement-plan.md` | Draft restructuring plan for `docs/` (audience-oriented navigation). |
| `gap-analysis-plan.md` | Draft gap analysis of the codebase against `docs/roadmap.md`. |
